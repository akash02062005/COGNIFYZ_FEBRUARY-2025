COGNIFYZ WEB DEVELOPMENT INTERNSHIP (FEBRUARY 2025)

Welcome to the official repository for the Cognifyz Web Development Internship (February 2025). This repository contains a curated series of front-end projects built using HTML, CSS, JavaScript, and Bootstrap 5 to demonstrate core concepts of web layout design, responsive formatting, dynamic browser interactions, and popular component-driven frameworks.

REPOSITORY STRUCTURE AND FILES:

  cog task 1.html & cog task 1.css: Static professional business portfolio landing page built using semantic HTML5 and custom CSS3 Grid/Flexbox.
    cog task 2.html, css, & js: Interactive webpage demonstrating dynamic color toggling, client-time hourly greetings, and a real-time arithmetic calculator.
      cog task 3.html: Bootstrap 5 gym portal ("Fitness Hub") showcasing a carousel banner, responsive program cards grid, and a collapsible FAQ accordion. Note that the carousel images reference ./fitness1.jpeg, but the physical file is named "fitness 1.jpeg" (with a space) in the repository.
        cog task 4.html & cog task 4.css: Fully responsive refactor of Task 1 leveraging CSS media queries (@media screen and max-width 480px) to scale grid layouts and typography for mobile screens.

        TECHNICAL BUGS AND FIX RECOMMENDATIONS:

        In Task 3, the Bootstrap carousel slider and program cards reference "./fitness1.jpeg" inside the img tags. However, the physical image file committed to the repository is named "fitness 1.jpeg" (with a space). This mismatch results in broken images on local loading. To resolve this, simply rename the image file to "fitness1.jpeg" or update the HTML image tags to target "fitness 1.jpeg".

        HOW TO RUN LOCALLY:

        Prerequisites: All tasks run entirely in any modern web browser without any package installations.

        Steps to run:
        1. Clone the repository: git clone https://github.com/akash02062005/COGNIFYZ_FEBRUARY-2025.git
        2. Navigate to the folder: cd COGNIFYZ_FEBRUARY-2025
        3. Open any .html file by double-clicking it or dragging it into your browser (Chrome, Firefox, Safari, or Edge) to view the live responsive rendering.
